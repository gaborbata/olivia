# Setup rclone for R2

* Install rclone e.g.: `sudo apt install rclone`, `pkg install rclone`
* In Cloudflare R2 generate an Access Key to obtain `access_key_id` and `access_key_secret`
* Configure rclone with `rclone config`:
  * Create new remote (by selecting `n`).
  * Select a name for the new remote. For example, use `r2`.
  * Select the Amazon S3 Compliant Storage Providers storage type.
  * Select Cloudflare R2 storage for the provider.
  * Select whether you would like to enter AWS credentials manually, or get it from the runtime environment.
  * Enter the AWS Access Key ID: `access_key_id`.
  * Enter AWS Secret Access Key (password): `access_key_secret`.
  * Select the region to connect to (optional/auto).
  * Select the S3 API endpoint: `https://<Account ID>.r2.cloudflarestorage.com`

## Edit an existing rclone configuration

```
$ rclone config file

Configuration file is stored at:
~/.config/rclone/rclone.conf

$ nano ~/.config/rclone/rclone.conf

[r2]
type = s3
provider = Cloudflare
access_key_id = abc123
secret_access_key = xyz456
region = auto
endpoint = https://<accountid>.r2.cloudflarestorage.com
```

## List bucket

`$ rclone tree r2:my-bucket-name`

## Sync bucket

Important: Since this can cause data loss, test first with the `--dry-run` or the `--interactive/i` flag.

`$ rclone sync --interactive SOURCE remote:DESTINATION`

## Example script

```
#!/bin/sh

if [ "$1" = "download" ]; then
  rclone copy -v -c r2:my-bucket-name asset/content
elif [ "$1" = "sync" ]; then
  rclone sync -v -c asset/content r2:my-bucket-name
else
  echo "Invalid command specified: '$1'"
  echo "Usage: r2sync.sh [download|sync]"
fi
```
